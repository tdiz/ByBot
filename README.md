# ByBit Trading Bot

Автоматизированный торговый бот для биржи ByBit.

## 🔐 Безопасность API Ключей

**КРИТИЧЕСКИ ВАЖНО:** Никогда не коммитьте файлы с API ключами в репозиторий!

### Защитные меры:

1. **`.gitignore`** - автоматически исключает файлы с секретами:
   - `.env` - ваш файл с реальными ключами
   - `config.ini`, `secrets.json` - другие файлы с конфигурацией
   - Все файлы логов и временные файлы

2. **`.env.example`** - шаблон конфигурации БЕЗ реальных ключей

### Первичная настройка:

```bash
# 1. Скопируйте шаблон
cp .env.example .env

# 2. Откройте .env в редакторе
nano .env  # или используйте любой редактор

# 3. Замените значения на ваши реальные API ключи
# BYBIT_API_KEY=ваш_реальный_ключ
# BYBIT_API_SECRET=ваш_реальный_секрет
```

### Как получить API ключи:

1. Зайдите на [ByBit API Management](https://www.bybit.com/app/user/api-management)
2. Создайте новый API ключ
3. **Важно:** Настройте права доступа:
   - Для тестирования: только READ права
   - Для торговли: READ + TRADE (НЕ давайте права WITHDRAW!)
4. Сохраните ключ и секрет в `.env` файл

### Проверка перед коммитом:

```bash
# Убедитесь что .env НЕ будет закоммичен
git status

# .env НЕ должен появляться в списке файлов!
# Если появился - НЕМЕДЛЕННО добавьте его в .gitignore
```

### Что делать если случайно закоммитили ключи:

1. **НЕМЕДЛЕННО** удалите API ключи на бирже
2. Создайте новые ключи
3. Очистите историю git (или сделайте новый репозиторий)
4. Проверьте что `.gitignore` настроен правильно
